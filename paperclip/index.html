PROGRAM

The full 65-position drum is shown. Unprogrammed positions are blank words and simply advance to the next position. Run pauses before external RIN A/B and after an ANS signal.

Instruction set and syntax

One drum position per source instruction. Comments begin with //, ;, or #. Markers are written as 1:, 2:, 3:, or 4: and may be repeated. Unprogrammed drum positions are blank; enter exactly 26 binary digits for a literal drum word or an explicit blank position.

RIN  A, B, 1-5; ANS       Read an encoder or core word into ACC; A/B pause only with ANS.  \nRIN  1-5 0-F                Initialise a core word with one hexadecimal digit.
ADD  -                      Add X to ACC, then clear X; DISPLAY automatic.
SUB  -                      Subtract X from ACC, then clear X; DISPLAY automatic.
SHR  1-4                    Shift ACC/extension right; DISPLAY automatic.
SHL  1-4                    Shift ACC/extension left; DISPLAY automatic.
TRA  -                      Copy ACC to X; DISPLAY automatic.
RUT  TENS and/or UNITS; ANS  Show ACC as one hexadecimal digit; DISPLAY automatic.
STO  1-5                    Store ACC in the numbered core word; DISPLAY automatic.
COJ  1-4                    If 2^4/SIGN is 1, roll to the first matching marker; DISPLAY automatic.
JUP  1-4                    Roll to the first matching marker (1-3 forwards, 4 backwards).

For RIN and STO, the first numeric operand 1-5 selects that core word and automatically includes the physical C contact.
TENS assembles as the 10^1 contact; UNITS as the 10^0 contact.
Examples: RIN 1 reads core word 1; RIN 2 5 initialises core word 2 to 0101; STO 4 stores ACC in core word 4. CORE1-CORE5 remain accepted as aliases.  \nFor RIN core initialisation, the hexadecimal nibble is assembled onto shared lines 1-4: line 1 = 2^0 through line 4 = 2^3. These contacts remain visible to JUP/COJ searches.
INPUT A/B accept exactly one hexadecimal digit (0-9, A-F). Plain RIN reads it immediately; add ANS to pause for input.
RUT writes a single hexadecimal digit (0-9, A-F) to TENS and/or UNITS. ANS lights and pauses Run. TENS and UNITS begin at 0.
TENS and UNITS may be selected together; ANS does not hold a separate value.
Markers prefix a drum word, for example 1: RIN B. The same marker may occur at several positions; arbitrary symbolic labels are not accepted.  
The current drum word remains selected until execution completes. Ordinary instructions then advance one position; a taken JUP/COJ remains at the marker found.  
SHL/SHR move bits through the five accumulator stages and four extension stages; X is separate.
When DISPLAY is active, the ACCUMULATOR and EXTENSION lamps appear amber. Raw 26-bit words are never changed by the assembler.
