PROGRAM

The full 65-position drum is shown. Execution pauses when it reaches an unprogrammed blank drum position, so the first blank row after a program acts as its end. Run also pauses before external RIN A/B and after an ANS signal.

Instruction set and syntax

One drum position per source instruction. Comments begin with //, ;, or #. Markers are written as 1:, 2:, 3:, or 4: and may be repeated. Unprogrammed drum positions are blank; enter exactly 26 binary digits for a literal drum word or an explicit blank position.

RIN  A, B, 1-5; ANS       Read an encoder or memory word into ACC; RTN automatic; A/B pause only with ANS.  
RIN  1-5 0-F                Initialise a memory word with one hexadecimal digit.
ADD  -                      Add X to ACC, then clear X; RTN automatic.
SUB  -                      Subtract X from ACC, then clear X; RTN automatic.
SHR  1-5                    Shift ACC/extension right using C1-C5; RTN automatic.
SHL  1-5                    Shift ACC/extension left using C1-C5; RTN automatic.
TRA  -                      Copy ACC to X; RTN automatic.
RUT  MSH and/or LSH; ANS     Show ACC as one hexadecimal digit; RTN automatic.
STO  1-5                    Store ACC in the numbered memory word; RTN automatic.
COJ  1-4                    If 2^4/SIGN is 1, roll to the first matching marker; RTN automatic.
JUP  1-4                    Roll to the first matching marker (1-3 forwards, 4 backwards).

For RIN and STO, the operand 1-5 selects WORD 1-5. Ordinary RIN transfers from A, B, or memory assert RTN; a memory read also asserts C. RIN initialisation asserts neither C nor RTN. STO does not assert C but does assert RTN.
MSH assembles as the physical TENS (10^1) contact; LSH as the physical UNITS (10^0) contact.
Examples: RIN 1 reads WORD 1; RIN 2 5 initialises WORD 2 to 0101; STO 4 stores ACC in WORD 4.  
For RIN word initialisation, the hexadecimal nibble is assembled onto shared lines 1-4: line 1 = 2^3 through line 4 = 2^0. These contacts remain visible to JUP/COJ searches.
INPUT A/B accept exactly one hexadecimal digit (0-9, A-F). Plain RIN reads it immediately; add ANS to pause for input.
RUT writes a single hexadecimal digit (0-9, A-F) to MSH and/or LSH; these drive the physical TENS/UNITS decoder outputs. ANS lights and pauses Run. TENS and UNITS begin at 0.
MSH and LSH may be selected together; ANS does not hold a separate value.
Markers prefix a drum word, for example 1: RIN B. The same marker may occur at several positions; arbitrary symbolic labels are not accepted.  
The current drum word remains selected until execution completes. Ordinary instructions then advance one position; a taken JUP/COJ remains at the marker found.  
SHL/SHR use C1-C5 to encode the shift count and move bits through the five accumulator stages and four extension stages; X is separate.
When RTN is active, the ACCUMULATOR and EXTENSION lamps appear amber. The PROGRAM summary shows the book-style four-digit ORDER and six-digit ADDRESS fields in octal. Raw 26-bit words are never changed by the assembler.
